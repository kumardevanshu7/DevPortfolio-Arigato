## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kumardevanshu7/DevPortfolio-Arigato.git
   cd DevPortfolio-Arigato
   ```

2. **Start the local server:**
   ```bash
   node server.js
   ```

3. **Open in browser:**
   Navigate to `http://localhost:3000` (or the auto-selected open port).

---

## 🚢 Deployment (Vercel)

This portfolio is built as a zero-build-dependency static web application:
1. Push repository to GitHub.
2. Import project in [Vercel](https://vercel.com).
3. Select **Framework Preset:** `Other`.
4. Deploy directly with instant global CDN caching.
